## 🚀 Key Features

1. **4-Language Seamless Localization (100% Coverage)**:
   - 🇺🇸 English (Default Global)
   - 🇰🇷 한국어 (Korean)
   - 🇯🇵 日本語 (Japanese)
   - 🇪🇸 Español (Spanish)
   - *Instant 1-click header switcher dynamically translates 164 UI keys, 9 FinTech categories, table headers, and the PayPal modal.*

2. **Mathematical Balance Reconciliation**:
   - Automated assertion: `Opening Balance + Total Deposits - Total Withdrawals == Closing Balance`.
   - Real-time zero-variance badge (`✓ Reconciled ($0.00 Variance)`) and discrepancy alerts.

3. **Multi-Format Export Pipeline**:
   - **Excel (.xlsx)**: With native SUM formulas and custom accounting styles.
   - **CSV**: Standard comma-delimited transaction feed.
   - **QuickBooks (.QBO)**: Intuit Web Connect format for 1-click import.
   - **Xero / Sage (.OFX)**: Standard Open Financial Exchange ledger format.
   - **Batch ZIP**: Multi-file batch bundling using JSZip.

4. **Multi-Tier Monetization Pipeline**:
   - **Free Starter**: 3 free pages / month.
   - **Pro Plan ($19/mo)**: 250 pages, QBO & OFX, multi-file batch queue.
   - **CPA Firm Plan ($49/mo)**: 1,500 pages, multi-client entity workspace, regex tax rules engine, audit certificates, and REST API access.
   - **PayPal Merchant Pipeline**: Full Smart Button modal with localized text and instant sandbox testing simulation.

5. **Zero-Credit Demo Experience**:
   - Global bank statement benchmarks (JPMorgan Chase, Bank of America, American Express, Barclays UK, KB Kookmin) are completely free to test and never consume user conversion quota.
